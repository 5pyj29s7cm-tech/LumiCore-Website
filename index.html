COMMON QUESTIONS

开始之前，你可能想问

使用 LumiCore，必须先安装本地模型吗？

可以按配置使用官方 API 等云端模型，也可以接入本地模型。本地模型需要另外准备运行服务与模型文件；具体设置请查看项目部署文档。

本地优先，是否意味着内容都不会发送到云端？

工作区与记忆以本地存储为主。选择云端模型时，处理任务所需的内容会发送到所选服务。请根据资料类型选择模型，并核对模型与工具设置。

API 调用说明和充值入口在哪里？

模型接入请查看官方 API 帮助；账户充值请前往充值控制台。使用 API 时还需要在调用端配置自己的凭据。

遇到问题，如何提供有效的反馈？

请记录系统版本、操作步骤、预期结果和实际现象，通过GitHub Issues反馈。分享截图或日志前，请移除密钥和私人内容。
